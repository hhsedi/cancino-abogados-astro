# Patrones prohibidos — Cancino Abogados

Codex debe evitar estos patrones:

1. Copiar la estructura exacta de EJAM.
2. Usar textos similares a EJAM.
3. Usar métricas inventadas.
4. Usar testimonios inventados.
5. Usar imágenes genéricas de abogados, balanzas o martillos.
6. Crear un hero genérico con título, bajada, dos botones y fondo degradado sin personalidad.
7. Usar cards repetidas con íconos sin contenido real.
8. Usar frases vacías como:
   - Soluciones legales integrales.
   - Excelencia a tu servicio.
   - Comprometidos con tus derechos.
   - La mejor asesoría legal.
   - Resultados garantizados.
9. Usar diseño tipo SaaS tecnológico si el cliente es abogado.
10. Usar exceso de animaciones.
11. Crear secciones decorativas que no aporten confianza o conversión.
12. Cambiar el branding de Cancino Abogados sin justificación.
13. Usar colores que no correspondan a la identidad visual del proyecto.
14. Sobrecargar la página con efectos visuales.
15. Usar textos largos sin jerarquía ni escaneo visual.
